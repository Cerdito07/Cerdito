Volver a la web

Información de privacidad de la web

Al acceder a la página de Alejandro se generan avisos de visitas. Esta función trata datos técnicos de conexión y de dispositivo para conocer el número de accesos y recibir una notificación de cada visita en Discord.

Qué datos se obtienen automáticamente

La página genera una notificación de visita con IP pública y datos técnicos suministrados por el navegador: fecha, navegador y agente de usuario, sistema operativo y tipo de dispositivo estimados, idioma, plataforma, pantalla y ventana, hora y zona horaria, memoria y núcleos aproximados si son compatibles, capacidades táctiles, preferencias de accesibilidad, cookies habilitadas, referencia de origen (solo dominio, cuando exista) y señales técnicas indicativas —no concluyentes— de automatización. El contador utiliza JSONBin.

Para la IP se consulta ipify y dos bases públicas de geolocalización, IPWho.is e ipapi.co, cuando están disponibles. Pueden devolver país, región, ciudad, código postal, coordenadas geográficas estimadas del área, operador, organización, ASN y zona horaria. La información puede ser imprecisa o contradictoria: las coordenadas de IP no identifican una vivienda ni el punto en que está la persona. Una IP tampoco permite verificar con fiabilidad si hay VPN, proxy o Tor mediante estos servicios.

Estadísticas de interacción opcionales

Solo si pulsas «Permitir estadísticas» se registran en esta visita el tiempo estimado de permanencia, clics en botones y enlaces (sin el contenido de formularios), desplazamiento máximo de página, visibilidad de la pestaña, parámetros de campaña UTM, conexión disponible y datos de batería si el navegador los permite. Si pulsas «Rechazar estadísticas», no se activa ese seguimiento. Esta elección se aplica a la visita actual y no se almacena para futuras visitas.

Ubicación del dispositivo (GPS opcional)

La ubicación más precisa no se solicita automáticamente. Solo si pulsas «Compartir ubicación precisa (opcional)» y aceptas la solicitud de tu navegador se obtendrán coordenadas y el margen de precisión informado por el dispositivo, para incorporarlos al aviso de la visita. Puedes negarte sin perder acceso a la web. Requiere HTTPS y no activa cámara ni micrófono.

Servicios externos

Los servicios ipify, IPWho.is y ipapi.co reciben consultas relativas a la IP. Los datos de visita se envían a Discord mediante un webhook. El contador usa JSONBin. Estos servicios tienen sus propias políticas de tratamiento de datos.

Finalidad, conservación y contacto

La finalidad es contabilizar visitas, emitir avisos técnicos y, únicamente cuando se autorice, añadir estadísticas de interacción o ubicación del dispositivo. Los mensajes pueden permanecer en el canal de Discord hasta su eliminación; los servicios externos tienen sus propios periodos de retención. Es responsabilidad de quien gestiona la web documentar la base jurídica del aviso básico, las condiciones de los tratamientos opcionales, los plazos de conservación y las transferencias internacionales aplicables antes de publicar este sistema.

Para consultar sobre los datos o solicitar la eliminación de avisos, utiliza la página de contacto.
